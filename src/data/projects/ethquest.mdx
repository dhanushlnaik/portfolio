## Overview

**ETHQuest** is a game I built for the EIPsInsight Impact Booth at **Devcon 8 in Mumbai (Nov 3–6, 2026)**. People scan a QR code at the booth, play short games across five worlds, earn XP that the server verifies, and redeem it for real swag with a single-use QR.

The tagline we worked from: *Ethereum is serious. Learning about it doesn't have to be.*

## What you can do

- **Quick quests**: trivia, upgrade history, real All Core Devs decisions and EIP hunts.
- **Collect EIP trading cards**: all 392 proposals as pixel cards. Open packs, complete sets, gift duplicates.
- **Battle**: best-of-3 card duels on Lore, Buzz, Links and Stage. You challenge friends by QR.
- **No sign-up wall**: you start with two free packs straight away and can save your profile with a passkey whenever you like.

## How it's built

- **Next.js 16** (App Router, Cache Components, Turbopack) with React 19, TypeScript and Tailwind v4.
- **Prisma 7 + PostgreSQL** using `@prisma/adapter-pg`. No Supabase, Firebase or Redis.
- ETHQuest writes only to **its own `ethquest` schema** inside the EIPsInsight database. It reads EIPs, snapshots, upgrades and protocol calls with raw SQL, and falls back to EIPsInsight's public RPC if the database can't be reached.
- **Passkeys** (`@simplewebauthn`) handle accounts, so there are no passwords to type on a crowded expo floor.
- XP is computed on the server, and swag codes are single-use, so a modified client can't farm rewards.

## Why it mattered

Devcon visitors give a booth maybe thirty seconds. Everything was designed for that: one tap to start, short rounds, and visible progress. The answers to every quest live on EIPsInsight, so the game also brings people back to the real product.
