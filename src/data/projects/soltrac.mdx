## The problem

A lot of Solana DeFi transactions fail. Users get a generic error and developers get raw logs. Was it slippage, a stale blockhash, the compute budget, an account conflict? You usually have to dig to find out.

## What SolTrac does

```
Transaction (unsigned) → soltrac-sdk → Risk score 0-100 + root cause + fix
```

- **Dual-pass simulation**: a baseline run plus an optimistic run before anything is signed.
- **8 weighted risk signals** scored from live RPC data.
- **100+ entry error taxonomy** that matches failures across 26 DeFi protocols.
- A **SEND / REVIEW / DO_NOT_SEND** verdict.
- **Three-tier explainer**: deterministic rules first, then log patterns, and AI only when neither matches.

It comes as an **npm SDK**, a **web app** (paste a signature, no wallet needed) and a **CLI**. You can also get wallet alerts by webhook.
