## Overview

**EasyFarm** lets farmers track their yield and sell produce directly to buyers nearby. We kept the UI very plain on purpose, since a lot of the people using it weren't used to web apps.

## Key Features

- **Yield dashboard**: charts of yield over time.  
- **Community**: talk to other farmers.  
- **Works on cheap phones**: that's what most farmers have.
