## Overview

**ClockThatDaily** is a daily game like the NYT ones, except it's about the internet. New questions every day, about four minutes to play, covering cinema, gaming, anime, music and brainrot.

## The four tracks

- **Emojidle**: decode a movie, show, game or song from five emoji clues, with three guesses.
- **Bad Plot**: name the work from a deliberately terrible plot summary.
- **Soundbite**: identify the clip.
- **Cluster**: group the connected items.

## Streaks and Aura

You earn **Aura**, keep a **streak** going and show up on a **global leaderboard**. Visually it looks like a printed catalogue, with numbered "artifacts" and a press date on each day's set.

## Built with

Next.js and TypeScript, deployed on Vercel. The source is private for now.
