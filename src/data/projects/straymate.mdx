## Overview

**StrayMate** is a web app for getting stray animals adopted. If you've found a stray, you post it. If you want to adopt or help out, you search the listings near you.

I built it solo in about three weeks, mostly to learn tRPC and Prisma properly.

## Key Features

- **Listings**: add, edit and remove strays with photos and details.  
- **Sign-in**: NextAuth.js.  
- **Search & Filter**: find listings by location or category.  
- **Prisma + PostgreSQL**: typed database access, with Zod validation on every form.  
- **UI**: Tailwind CSS, works on phones.
