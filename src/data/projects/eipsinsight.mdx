## Overview

**EIPsInsight** tracks Ethereum Improvement Proposals: what state each one is in, who's editing it, and what's going into the next upgrade. I've worked on it at Avarch since 2022, starting with the backend scheduler that pulls EIP data from GitHub.

## Key Features

- **EIP browser**: filter proposals by category or status.  
- **Nginx**: self-hosted production.  
- **Two branches**: dev on Vercel, production on our own server.  
- **Auth**: NextAuth with database sessions.
