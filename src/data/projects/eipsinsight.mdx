## Overview

**EIPs Insights** is a web platform that provides structured insights into Ethereum Improvement Proposals (EIPs). It helps developers, researchers, and blockchain enthusiasts easily navigate technical discussions and proposal statuses.

## Key Features

- **EIP Browser** — Filter and explore proposals by category or status.  
- **Nginx Deployment** — Self-hosted production setup.  
- **Two-Branch Workflow** — Dev branch on Vercel, production on server.  
- **Secure Auth** — NextAuth with database session handling.
